Everything a QA engineer needs for evidence

From one screenshot to a finished test-evidence document — without leaving the browser.

📸 Capture anything

Visible, full page, area, element, dual select, split view, scroll box, mobile view, screen / app. Open menus stay in the picture.

🕒 URL & real time

A browser-style bar with the page address and the real date and time is stamped on every shot — proof that holds up.

✏️ Mark it up in seconds

Arrows, boxes, numbered badges, PASS / FAIL stamps, blur & redact, spotlight, magnifier, crop and frames.

🐞 Console & network

Put the errors and failed requests under the screenshot, or export them as text, JSON or HAR.

🎬 Record · trim · share

Tab, window or entire screen up to 4K / 60 fps, with sound, camera bubble, trim, GIF and timed repro steps.

👣 Every click becomes a step

The Step guide writes each click and typed field as a numbered step with a picture. Passwords are never written.

User Manual & Test Evidence

Two separate documents. Choose ＋ User Manual or ＋ Test Evidence whenever you add something.

  • Test cases with ID, precondition, expected & actual result, Pass / Fail / Blocked and bug ID — written once per test case, not for every click.
  • Checkpoints for the steps where you verify something.
  • Summary of passed, failed, blocked and not-run test cases.
  • User Manuals with sections, auto-written step titles, your logo and colour.
  • Export to Word (.docx), PDF, HTML or Markdown — and back up everything as one .zip.

Install in four steps

EvidenceKit is installed straight from GitHub — works in Chrome, Edge and Brave.

DownloadOn GitHub: Code → Download ZIP, then unzip it.
Developer modeOpen chrome://extensions and switch on Developer mode.
Load unpackedClick Load unpacked and pick the folder with manifest.json.
Pin itPin EvidenceKit in the toolbar — then press Alt+Shift+S.
